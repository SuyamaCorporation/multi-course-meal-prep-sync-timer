# Multi-Course Meal Preparation Sync Timer

Reverse-schedules up to 8 dishes from a target serve time so every course finishes simultaneously.

## Key Features

- Enter a target serve time and cook duration per dish; app computes the start time for each automatically
- Visual timeline bar chart shows all dishes scaled across the full preparation window
- Per-dish countdown cards with Start/Pause/Resume controls and audio beep at completion
- Colour-coded dishes (8 distinct colours) for quick visual identification
- localStorage persistence saves dishes and serve time across sessions
